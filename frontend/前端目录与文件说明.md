# 前端目录与文件说明

本文档说明 `frontend` 目录中每个文件夹和文件的作用，以及日常修改时应该关注的位置。

## 一、整体目录结构

```text
frontend/
├─ src/                 页面源代码
│  ├─ App.vue           主页面与页面功能
│  ├─ api.js            后端接口请求
│  ├─ main.js           前端程序入口
│  ├─ providers.js      AI 接口服务商的备用配置
│  └─ styles.css        页面样式
├─ .gitignore           不应提交或复制的文件清单
├─ index.html           浏览器加载的 HTML 入口
├─ package.json         项目信息、依赖和运行命令
├─ package-lock.json    锁定依赖的准确版本
├─ vite.config.js       Vite 开发服务器和代理配置
├─ run.bat              Windows 一键启动脚本
└─ README.md            前端安装与启动说明
```

运行 `npm install` 后会自动出现 `node_modules/`；运行 `npm run build` 后会自动出现 `dist/`。这两个目录都不是手写源码，因此当前精简版本没有包含它们。

## 二、`src` 源代码目录

`src` 是最重要的目录，前端页面的内容、交互逻辑、接口调用和样式都在这里。

### `src/App.vue`

整个诊疗页面的主组件，包含：

- 图片选择与上传；
- 作物选择；
- 症状填写；
- AI 服务商及 API 密钥配置；
- 发起诊断；
- 显示识别结果、诊疗建议和历史记录；
- 页面主要 HTML 结构与 Vue 交互逻辑。

如果要增加按钮、表单、结果模块或修改页面文字，通常从这个文件开始。

### `src/styles.css`

保存整个页面的外观样式，包括颜色、字体、间距、按钮、卡片、表单、弹窗以及手机端适配。

如果只想修改页面视觉效果，而不改变功能，主要编辑这个文件。

### `src/api.js`

统一负责访问后端接口。目前包含：

- 获取支持的作物：`GET /api/crops`；
- 检查后端状态：`GET /api/health`；
- 获取 AI 服务商：`GET /api/providers`；
- 测试 AI 接口连接：`POST /api/providers/test`；
- 提交图片并诊断：`POST /api/diagnoses`；
- 查询历史记录：`GET /api/diagnoses`。

以后后端新增接口时，建议先在这里增加对应的请求函数，再由 `App.vue` 调用。

### `src/providers.js`

保存 AI 服务商的前端备用列表，例如 DeepSeek、通义千问、智谱、Kimi 和自定义兼容接口。

正常情况下页面优先读取后端返回的服务商列表；如果后端服务商接口暂时不可用，可以使用这里的备用信息。

### `src/main.js`

前端程序的启动入口。它完成三件事：

1. 创建 Vue 应用；
2. 加载 `App.vue` 主页面；
3. 加载 `styles.css` 并把页面挂载到 `index.html` 中的 `#app` 节点。

一般不需要频繁修改这个文件。

## 三、根目录配置文件

### `index.html`

浏览器最先打开的 HTML 文件，提供页面标题、中文编码、手机端显示配置和 Vue 的挂载节点。

修改浏览器标签页标题或网页描述时，可以编辑这里的 `<title>` 和 `<meta name="description">`。

### `package.json`

前端项目的依赖与命令清单：

- `vue`：页面框架；
- `vite`：开发服务器和打包工具；
- `@vitejs/plugin-vue`：让 Vite 能够处理 `.vue` 文件；
- `npm run dev`：启动开发环境；
- `npm run build`：生成正式部署文件；
- `npm run preview`：预览打包结果。

增加或删除前端依赖时，这个文件会发生变化。

### `package-lock.json`

记录依赖的准确版本，保证不同电脑安装出的环境尽量一致。它由 npm 自动维护，通常不要手动编辑，也不要随意删除。

### `vite.config.js`

Vite 的运行配置。目前负责：

- 启用 Vue 支持；
- 使用 `5173` 端口启动前端；
- 把 `/api` 请求转发给云端服务器 `http://170.106.137.89`，因此健康检查实际访问 `http://170.106.137.89/api/health`。

因此开发时浏览器只需要访问 `http://localhost:5173`，前端会自动连接云端后端。如果云服务器地址发生变化，需要同步修改这里的 `target`。`target` 只填写服务器根地址，不要在末尾重复添加 `/api`。

### `run.bat`

Windows 一键启动文件。双击后会：

1. 进入当前前端目录；
2. 如果没有 `node_modules`，自动运行 `npm install`；
3. 运行 `npm run dev` 启动前端。

### `.gitignore`

告诉 Git 忽略不需要保存的内容，例如：

- `node_modules/`：本机安装的依赖；
- `dist/`：自动生成的打包结果；
- `.env.local`：本机私有环境配置；
- 日志文件。

### `README.md`

简要记录前端的安装方法、启动命令、访问地址和后端连接方式。

## 四、运行后自动生成的目录

### `node_modules/`

执行 `npm install` 后生成，存放 Vue、Vite 等第三方依赖。目录通常较大，可以随时通过 `package.json` 和 `package-lock.json` 重新安装，因此不需要复制或提交。

### `dist/`

执行 `npm run build` 后生成，里面是压缩后的正式网页文件。部署到 Nginx 等网页服务器时使用这个目录；继续开发页面时仍然修改 `src`，不要直接修改 `dist`。

## 五、页面与后端的工作流程

```text
index.html
    ↓ 加载
src/main.js
    ↓ 创建页面
src/App.vue
    ↓ 调用
src/api.js
    ↓ /api 请求由 Vite 转发
http://170.106.137.89/api 云端后端
```

`styles.css` 负责页面外观，`providers.js` 在需要时为 `App.vue` 提供备用的 AI 服务商信息。

## 六、常见修改位置

| 想要修改的内容 | 对应文件 |
|---|---|
| 页面文字、表单、按钮或功能 | `src/App.vue` |
| 颜色、布局、字体、手机端样式 | `src/styles.css` |
| 后端接口请求 | `src/api.js` |
| AI 服务商备用列表 | `src/providers.js` |
| 浏览器标题和网页描述 | `index.html` |
| 云端后端地址或前端端口 | `vite.config.js` |
| npm 依赖与运行命令 | `package.json` |

## 七、启动顺序

1. 启动 `frontend/run.bat`；
2. 浏览器访问 `http://localhost:5173`；
3. 前端会通过开发代理访问云端接口，无需启动本地 `backend`。

前端页面能打开但诊断失败时，请先访问 `http://170.106.137.89/api/health` 检查云端后端状态。
